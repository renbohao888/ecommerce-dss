# 电子商务大数据分析与智能决策支持系统

依据《电子商务大数据分析与智能决策支持系统》赛题要求构建的演示系统，
以 **Flask + 自研暗黑高级前端（本地 ECharts，离线可用）+ 机器学习模型** 实现，
完整覆盖赛题 6 大方向，并引入外部公开数据集增强功能。

## 功能模块

| 模块 | 说明 | 采用方法 |
| ---- | ---- | -------- |
| 数据总览 | 平台核心 KPI 与多维图表 | 统计聚合 |
| 用户行为与推荐 | 用户画像 + 个性化商品推荐 | 基于物品的协同过滤（Cos 相似度） |
| 商品销售预测 | 未来销售额/品类销量预测 | 随机森林时序回归 |
| 营销策略优化 | RFM 客户分层 + 个性化营销 | K-Means 聚类 + 规则策略 |
| 供应链风控 | 配送延迟风险预警 | 随机森林风险分类 |
| 商品价格优化 | 价格弹性估计 + 最优定价 | 对数回归弹性 + 定价公式 |
| 客户服务优化 | 满意度画像 + 投诉归因 + 风险客户预警 | 统计 + 规则策略 |
| 外部数据源 | 全球市场洞察（月度营收、国家/商品/客户分布） | 外部公开数据集分析 |
| AI 数据问答助手 | 右下角可拖动悬浮球，随时问答系统内各模块数据问题 | 意图识别 + 动态指标/图表 |
| 实时数据流（LIVE） | 系统内后台线程按固定节奏持续生成新订单/行为/评价，各模块结果自动重算并刷新，告别静态数据 | 流式数据引擎 + 定时重算 |

## 数据说明

- `data/users.csv`：来自《项目2：直播电商用户画像.xlsx》的 4544 个真实电商用户。
- `data/products.csv|orders.csv|behaviors.csv|reviews.csv`：
  由 `generate_data.py` 生成的商品、订单、浏览行为、评价等明细，支撑各分析/预测模块。
- `data/_online_retail.xlsx`：**自增公开数据集** —— UCI Machine Learning Repository 的
  「Online Retail」（2010-12 ~ 2011-12，英国零售电商，541,909 条交易），
  在赛题指定的阿里天池 Rec-Tmall 等基础数据之外，用于补充全球市场与生命周期洞察。
  > 该文件约 23MB，为避免 Git 推送超时**不属于仓库**；缺少时系统会在**首次访问「外部数据源」页**时
  > 自动从 UCI 下载（见 `ml/models.py` 的 `_ensure_online_retail()`）。公网部署环境首次打开 `/data` 会稍慢，之后已缓存。
  > **提交的 `电商智能决策支持系统.zip` 已按赛题“附加数据集”要求，将本数据集及其来源说明（`data/_online_retail_来源说明.txt`）一并打入 `data` 目录。**
  > **加载加速：** 数据目录另提供压缩缓存 `data/_online_retail.csv.gz`（约 7.6MB，秒级读取），
  > `external_data()` 会**优先读取该压缩缓存**（缺失时才回退到 xlsx/联网下载），以免首次打开 `/data` 页耗时数十秒。

## 实时数据流（LIVE）

- 系统内置一个后台流式数据引擎（`ml/live.py`），按默认每 3 秒生成一批新的订单/浏览行为/评价，
  并追加到内存中的实时数据表，滚动保留最近若干条。
- 各分析页面上方会出现 **LIVE 实时状态栏**（每 2 秒轮询 `/api/live`）：实时订单、实时 GMV、
  近 1 分钟下单数、平均客单、延迟单与延迟率等实时指标，并内置一条 **实时 GMV 走势迷你图**。
- 数据总览的「近 30 天每日销售额」图每 5 秒自动刷新（`/api/daily`），曲线会随实时订单持续变动。
- LIVE 栏右侧的 **“实时刷新”开关（默认开）** 会每 2 秒在后台**就地**刷新实时订单/GMV 等数字，
  不再整页刷新、页面不会闪跳（需要时也可随时暂停/恢复）。
- 各模块模型（推荐/预测/营销/风控/价格）由后台调度线程**定时“保温重算”**（`models.refresh()`，默认每 15 秒一次），
  在**后台线程**里基于含实时行的最新数据重建模型并整体替换，使推荐结果、销售预测、营销分层、风险预警与最优定价等
  随最新数据自动更新；由于模型缓存始终可用、不在请求线程里同步重训，**页面导航始终保持快速**。
- 系统启动时会**后台预训练**全部模型并预热外部数据集，因此各页面首次访问即命中缓存、无需额外等待。
- AI 数据助手问答时也会采用到含实时行在内的最新数据。
- 直播演示时可对比：打开页面后 **LIVE 数字持续跳动、GMV 曲线不断增长**，直观体现“活数据 + 实时决策”。

## 运行方法（Windows）

```bat
:: 1. 安装依赖（首次）
pip install -r requirements.txt

:: 2. 重新生成数据（若 data 目录下已有 CSV 可跳过）
python generate_data.py

:: 3. 启动系统
python app.py
```

浏览器打开 **http://127.0.0.1:5000** 即可访问。

也可以直接双击运行 `run.bat`（自动完成依赖安装与启动）。

> 系统启动时会在后台预训练各模块模型并预热外部数据集，各页面首次访问即命中缓存；后台定时“保温重算”负责让结果随实时数据更新，页面导航始终流畅。

## 公网部署

- 仓库已内置 `.gitignore`、`Procfile`（`web: python app.py`）与 `render.yaml`（Render 一键部署）。
- `app.py` 末尾已改为 `host='0.0.0.0'` 并读取平台 `PORT` 环境变量，可被云平台直接托管；实时数据流与定时重算线程会随服务一同运行。
- 「外部数据源」页依赖的 23MB 数据集不在仓库中，首次访问该页时系统会**自动从 UCI 下载**（见「数据说明」）。
- **演示部署地址（已上线）**：<https://ecommerce-dss.onrender.com> —— 本项目已实际部署于 Render 免费版；实例闲置后会自动休眠，首次访问约需 30~60 秒冷启动，随后即可正常访问。
- **Render（免费，推荐）**：push 到 GitHub 后，登录 [render.com](https://render.com) → New → **Blueprint** → 选择该仓库，即按 `render.yaml` 自动创建并部署。
- **Railway / PythonAnywhere** 亦可：它们需要监听平台注入的 `PORT` 与 `0.0.0.0`，本项目已兼容。
- **快速临时公网地址（无需注册）**：在本机运行 `python app.py` 后，执行
  `cloudflared tunnel --url http://127.0.0.1:5000`（Cloudflare Tunnel）或 `ngrok http 5000`，
  即可得到一条可访问的公网 URL（仅供演示，随本机与隧道进程存活）。


## 界面风格

- 暗黑高级主题（深空蓝渐变底色、玻璃拟态卡片、霓虹强调色）。
- 入场动画仅轻淡淡入（不位移、不缩放），页面导航干净利落、不跳动。
- 图表采用渐变填充、霓虹发光、圆角与动画等视觉效果（ECharts）。
- 右下角内置可拖动的 **AI 数据助手** 悬浮球，点击展开聊天面板，可用自然语言问答系统内各项数据并即时展示图表。
